# $log

**Description:** Logs a message.

**Usage:**
```
$log[Message]
```

**Arguments:**

|  Name   |     Description     | Type | Required | Spread |
|---------|---------------------|------|----------|--------|
| Message | The message to log. | any  | Yes      | No     |
