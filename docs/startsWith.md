# $startsWith

**Description:** Checks if a string starts with a specified prefix.

**Usage:**
```
$startsWith[String, Prefix]
```

**Arguments:**

|  Name  |       Description        | Type | Required | Spread |
|--------|--------------------------|------|----------|--------|
| String | The string to check.     | any  | Yes      | No     |
| Prefix | The prefix to check for. | any  | Yes      | No     |


**Source:** [$startsWith](https://raw.githubusercontent.com/threadrypper/bdjs/1.5/src/functions/startsWith.ts)
