# $c

**Description:** Represents a BDJS comment.

**Usage:** ```
$c[Comment]
```

**Arguments:**

|  Name   |       Description       | Type | Required | Spread |
|---------|-------------------------|------|----------|--------|
| Comment | The comment to display. | any  | Yes      | No     |
