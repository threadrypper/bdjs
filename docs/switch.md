# $switch

**Description:** Match a value against multiple cases.
Does not return any value.

**Usage:**
```
$switch[Value, Cases]
```

**Arguments:**

| Name  |     Description     | Type | Required | Spread |
|-------|---------------------|------|----------|--------|
| Value | The value to check. | any  | Yes      | No     |
| Cases | The cases to check. | any  | Yes      | No     |


**Source:** [$switch](https://raw.githubusercontent.com/threadrypper/bdjs/1.5/src/functions/switch.ts)
