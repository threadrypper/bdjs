# $endsWith

**Description:** Checks if a string ends with a specified suffix.

**Usage:**
```
$endsWith[String, Suffix]
```

**Arguments:**

|  Name  |       Description        | Type | Required | Spread |
|--------|--------------------------|------|----------|--------|
| String | The string to check.     | any  | Yes      | No     |
| Suffix | The suffix to check for. | any  | Yes      | No     |


**Source:** [$endsWith](https://raw.githubusercontent.com/threadrypper/bdjs/1.5/src/functions/endsWith.ts)
