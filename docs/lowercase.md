# $lowercase

**Description:** Converts a string to lowercase.

**Usage:** ```
$lowercase[String]
```

**Arguments:**

|  Name  |             Description             | Type | Required | Spread |
|--------|-------------------------------------|------|----------|--------|
| String | The string to convert to lowercase. | any  | Yes      | No     |


**Source:** [$lowercase](https://raw.githubusercontent.com/threadrypper/bdjs/1.5/src/functions/lowercase.ts)
