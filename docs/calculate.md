# $calculate

**Description:** Calculates a mathematical expression.

**Usage:**
```
$calculate[Expression]
```

**Arguments:**

|    Name    |         Description          | Type | Required | Spread |
|------------|------------------------------|------|----------|--------|
| Expression | The expression to calculate. | any  | Yes      | No     |


**Source:** [$calculate](https://raw.githubusercontent.com/threadrypper/bdjs/1.5/src/functions/calculate.ts)
