# $charCount

**Description:** Returns the number of characters in a string.

**Usage:**
```
$charCount[String]
```

**Arguments:**

|  Name  |              Description               | Type | Required | Spread |
|--------|----------------------------------------|------|----------|--------|
| String | The string to count the characters of. | any  | Yes      | No     |


**Source:** [$charCount](https://raw.githubusercontent.com/threadrypper/bdjs/1.5/src/functions/charCount.ts)
