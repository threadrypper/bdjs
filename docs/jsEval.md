# $jsEval

**Description:** Executes JavaScript code.

**Usage:** ```
$jsEval[Code]
```

**Arguments:**

| Name |    Description     | Type | Required | Spread |
|------|--------------------|------|----------|--------|
| Code | JS code to execute | any  | Yes      | No     |


**Source:** [$jsEval](https://raw.githubusercontent.com/threadrypper/bdjs/1.5/src/functions/jsEval.ts)
