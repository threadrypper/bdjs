# $uppercase

**Description:** Converts a string to uppercase.

**Usage:**
```
$uppercase[String]
```

**Arguments:**

|  Name  |             Description             | Type | Required | Spread |
|--------|-------------------------------------|------|----------|--------|
| String | The string to convert to uppercase. | any  | Yes      | No     |


**Source:** [$uppercase](https://raw.githubusercontent.com/threadrypper/bdjs/1.5/src/functions/uppercase.ts)
